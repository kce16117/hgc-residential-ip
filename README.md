## HGC住宅IP是什么，跟机房IP差在哪

差在 IP 的“户口”上。

HGC（环球全域电讯）是香港本土的宽带运营商，香港家庭拉光纤用的就是它家线路。从这类宽带池分出来的 IP，在 ipinfo 等数据库里会被标注为 ISP/住宅属性，而且不止一个数据库这么认——所谓“双 ISP”说的就是这个。它同时是原生 IP，归属地就在香港本地。

普通香港 VPS 的 IP 注册在数据中心名下。拿它去开亚马逊多账号、跑社媒矩阵，平台很容易把同机房的一串账号关联起来一锅端；住宅 IP 没有这个问题，这正是跨境卖家愿意为它付溢价的原因。

机器本身则要按“挂 IP 的壳”来理解。测评机用的是至强 E5-2680 v4，老一代至强，跑代理、挂机、看 4K 流媒体、小型网站都够用，重度计算就别指望了。另外只有 IPv4、没有 IPv6，KVM 虚拟化，支持装 Windows——需要远程桌面环境的用户可以留意这点。
